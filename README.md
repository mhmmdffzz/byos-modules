# byos-modules

Kumpulan module sumber musik (Bring Your Own Source).

## Navidrome (FLAC)
1. Isi `baseUrl`, `user`, `token`, dan `salt` di aplikasi atau di file module.
2. Import URL manifest ke 8SPINE:
   https://raw.githubusercontent.com/mhmmdffzz/byos-modules/main/manifest.json

   Module ini hanya memutar file yang tersimpan di server milik Anda.
